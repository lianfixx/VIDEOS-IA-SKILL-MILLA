# Espacios

Cada marca tiene su carpeta y no se mezcla con las demás:

| Espacio | Carpeta | Producciones (privadas) |
|---|---|---|
| Personal de Emi | `espacios/personal/` | `productions/personal/` |
| MILLA ABOGADOS | `espacios/milla/` | `productions/milla/` |
| Castorena Abogados | `espacios/castorena/` | `productions/castorena/` |
| PAN / Acción Juvenil | `espacios/pan/` | `productions/pan/` |

Lo que se aprende en un espacio vale para todos (`espacios/APRENDIZAJES.md`); en la carpeta de cada marca solo queda su espíritu: tono, público, voz, límites y aprobaciones.

En cada una: `perfil.json` (colores, voz, `voz_comentario` candidata, tono; lo lee `vox.py`), `ideas.md` (temas pendientes) y, cuando exista, `MARCA.md` con la guía de identidad y sus fuentes. `vox.py proyecto` se niega a crear una producción fuera de la carpeta de su espacio.
